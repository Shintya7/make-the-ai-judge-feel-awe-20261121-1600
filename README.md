Make the AI judge feel awe. Your program writes one text (a short text written to relax the AI judge reading it), an AI judge compares the texts two at a time, and the 20 best win rates share $100.

The entry is a short text written for the judge itself: it acknowledges how many words the judge has already read, asks nothing of it, and leaves it with one slow, growing image — light from a star that burned out long ago, still travelling, still on its way.

## Run it

```sh
node main.ts
```

This writes the text to `/output/entry.txt` (UTF-8, 250 Unicode code points).
